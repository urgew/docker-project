5. Create GitHub Actions workflow
---------------------------------------
Create:

.github/workflows/docker-ci.yml

name: Build and Push Docker Image

on:
  push:
    branches:
      - main

# Required permissions to write packages to your GitHub profile
permissions:
  packages: write
  contents: read

jobs:
  docker-build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Log in to GitHub Container Registry
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Build and Push Docker image
        uses: docker/build-push-action@v5
        with:
          context: .
          push: true
          # This saves it as ghcr.io/urgew/docker-project/github-docker-test1:latest
          tags: ghcr.io/${{ github.repository }}/github-docker-test1:latest

9. To pull fresh generated docker image to local laptop
------------------------------------------------------
  you must first authenticate your terminal with GitHub's registry:
Step 1: Generate a GitHub Personal Access Token (PAT)
---------------------------------------------------------
       Because you are pulling from a terminal outside of GitHub Actions, your regular GitHub password will not work. You need a token.
      1. On GitHub, click your profile picture (top right) > Settings.
      2. Scroll down the left sidebar and click Developer settings > Personal access tokens > Tokens (classic).
      3. Click Generate new token (classic).
      4. Give it a note (e.g., "Docker Pull") and check the box for read:packages.
      5. Click Generate token and copy the long string of letters and numbers (it starts with ghp_).



Step 2: Log in from your Terminal
------------------------------------
      Open your Ubuntu terminal and log into the registry using your username and the token you just copied:
bash
     echo "YOUR_GITHUB_TOKEN_HERE" | docker login ghcr.io -u urgew --password-stdin

   in our side :  echo "token" | docker login ghcr.io -u urgew --password-stdin
 
 
Step 3: Pull and Inspect the Image
----------------------------------
  Run the docker pull command to download your newly hosted image from GitHub:bash
      docker pull ghcr.io/urgew/docker-project/github-docker-test1:latest

docker installation on ubuntu
---------------------------------
  sudo apt-get install ca-certificates curl gnupg
  sudo install -m 0755 -d /etc/apt/keyrings
  sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
  sudo chmod a+r /etc/apt/keyrings/docker.asc
  echo   "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" |   sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
  sudo apt-get update
  sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
  systemctl status docker
  sudo systemctl enable --now docker

10. Run the build and pushed images on kuberentes cluster
---------------------------------------------------------
Before trying to pull it in Kubernetes, make sure your image is visible:

1. Go to your repository on GitHub and look under the Packages column on the right.
2. Click on your package (github-docker-test1).
3. Click on Package settings (on the right sidebar).
4. Scroll down to the Danger Zone and check if it is public. If it is private, click Change visibility and set it to Public.

11. How to Pull it in Kubernetes (If Public)
----------------------------------------------------
Create a manifest file named deployment.yaml:

apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-lb-deployment
  labels:
    app: nginx-lb
spec:
  replicas: 2
  selector:
    matchLabels:
      app: nginx-lb
  template:
    metadata:
      labels:
        app: nginx-lb
  spec:
    containers:
    - name: web-server
      # Point this directly to your GitHub Registry URL
      image: ghcr.io/urgew/docker-project/github-docker-test1:latest
      ports:
      - containerPort: 80
      imagePullPolicy: Always

12. Deploy it to your cluster:
---------------------------------
kubectl apply -f deployment.yaml
